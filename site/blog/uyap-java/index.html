UYAP için Java gerekir mi, hatalar nasıl çözülür?

Halit Sever · 28 Kasım 2026

UYAP ile ilgili programların bir kısmı Java ile çalışır, bir kısmı artık Java istemez. Hangisinin ne istediğini bilmek, gereksiz kurulumdan ve sık görülen iki hatadan kurtarır. Bu yazı UYAP'ın ve Kamu SM'nin kendi açıklamalarına dayanıyor.

Hangi program Java ister?

  • UYAP Editör, Mac: UYAP Editör sayfasına göre işlemcinize uygun güncel sürümü (Intel ya da Apple Silicon) kurduğunuzda Java kurmanıza gerek yoktur. Big Sur 11 ve öncesi için olan Intel sürümü ise uyumlu bir Java ister. Ayrıntı UYAP Editör Mac yazısında.
  • UYAP Editör, Windows: UYAP Vatandaş Portal sıkça sorulan sorular belgesi editör açılırken "Javaw bulunamıyor" hatası alan kullanıcıya bilgisayarda Java kurulu olup olmadığını kontrol etmesini söyler. Hata alıyorsanız aşağıdaki adımlar geçerlidir.
  • E-imza işlemleri: Kamu SM Sürücü Yükleme Servisi, Bireysel İşlemler ve başvuru portalları gibi Kamu SM hizmetleri için Java 1.8 veya üzerini şart koşar. PIN oluşturma ve kilit çözme bu kapsama girer.

Java nereden indirilir?

UYAP'ın SSS belgesi, uyumlu Java'nın Vatandaş Portal'daki Programlar sayfasından indirilmesini söyler. Portala girdikten sonra sol menüdeki Programlar sekmesinde UYAP ile kullanılacak programların listesi bulunur. "UYAP Java indir" diye arayıp tanımadığınız sitelerden kurulum dosyası indirmeyin.

Hata: Javaw Windows tarafından bulunamıyor

SSS belgesinin çözümü iki adımdır. Önce Java'nın kurulu olup olmadığına bakın, değilse Programlar sayfasından kurun. Java kuruluysa ve hata sürüyorsa Java'nın klasörünü Path'e ekleyin:

  1. Java'nın bin klasörünü bulun ve yolunu kopyalayın. Belgedeki örnek:
C:\Program Files (x86)\Java\jreX.X.X_XXX\bin
  1. Masaüstünde Bilgisayar simgesine sağ tıklayıp Özellikler'i açın.
  2. Gelişmiş Sistem Ayarları › Gelişmiş › Ortam Değişkenleri'ne girin, Path'i seçip Düzenle'ye basın.
  3. Var olan değeri silmeden en başa kopyaladığınız yolu yapıştırın ve sonuna noktalı virgül koyun.
  4. Pencereleri Tamam ile kapatın ve editörü yeniden açın.

Windows 10 ve 11'de Ortam Değişkenleri penceresi Path'i satır satır gösterir. Orada Yeni deyip yolu ekleyin ve Yukarı Taşı ile en üste alın; noktalı virgül gerekmez.

Hata: Application Blocked by Java Security

SSS belgesi, yeni UYAP uygulamasını açarken bu hatayı alanlar için şu adımları verir:

  1. Başlat menüsünden Denetim Masası'nı açın ve Java'ya tıklayın.
  2. Java Control Panel'de ilk sekme olan General'da, Temporary Internet Files bölümündeki View düğmesine basın.
  3. Açılan penceredeki bütün uygulamaları kırmızı çarpıyla silin.
  4. Uygulamayı yeniden çalıştırın.

Editör yine açılmıyorsa

Java sorunu çözüldüğü halde siyah ekran gelip gidiyorsa sebep çoğunlukla editörün eski sürümü ya da bozuk ayar dosyalarıdır. UYAP Editör sayfasının önerdiği sıra (son sürüm, .uki klasöründeki ayar dosyalarını silme, temiz kurulum) UYAP Editör açılmıyor yazısında.
