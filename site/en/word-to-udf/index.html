What the UDF keeps

The converter reads the text and formatting inside the .docx file and writes them in the UDF structure the UYAP Document Editor saves. The text goes in as text, not as page images:

  • Text with Turkish characters, font and size, bold, italic, underline, strikethrough, colours, highlight, subscript and superscript
  • Paragraph alignment, indents, hanging indents, line spacing, paragraph spacing and tab stops
  • Numbered and bulleted lists, as the editor's own lists
  • Tables with column widths, horizontally merged cells and borders
  • Images (PNG, JPEG, GIF, BMP; other types are converted to PNG)
  • Paper size, landscape pages, margins and page breaks
  • Headers, footers and page numbers (such as "Page 1 / 3")
  • Footnotes, with their numbers, at the end of the document

Tracked changes are carried over as if they had been accepted.

Limitations

  • Only .docx is read. Open an old .doc file in Word, use File → Save As and choose "Word Document (.docx)", then try again. Remove the password from protected documents first.
  • The UYAP Document Editor lays out lines with its own font measurements, so some line and page breaks may fall differently than in Word. Open the UDF in the editor and check it before filing.
  • The editor has no vertically merged cells and no cell shading. Vertically merged cells are written as separate cells and cell colours are dropped. Dot leaders on tab stops are not shown by the editor.
  • Text box content becomes ordinary paragraphs. Shapes, charts, comments and EMF/WMF images are left out.
  • With more than one section, all pages use the page layout of the last section.
  • The UDF is unsigned. Sign it in the editor with an e-signature or mobile signature if needed.

If the look must not change at all, save the Word file as PDF and use the PDF to UDF converter. Each page then becomes an image in the UDF, so the text is not editable. The reverse direction is the UDF to Word converter.

Frequently asked questions

How do I convert a Word document to UDF?

+
Drop the Word file (.docx) on this page. The UDF is ready within seconds and the download button saves it. Open it in the UYAP Document Editor to check it before filing.

Is the text in the UDF editable?

+
Yes. The text goes into the UDF as text, not as page images, so it can be edited, searched and copied in the UYAP Document Editor.

Can old .doc files be converted?

+
No, the tool reads .docx only. Open the .doc file in Word, use File, Save As and choose Word Document (.docx), then drop that file here.

Is my file uploaded to a server?

+
No. The file is read in your browser and the UDF is built there too. No file is sent to a server.
