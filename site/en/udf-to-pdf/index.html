What the PDF keeps

A UDF file is a ZIP archive whose XML holds all of the text and its formatting. The converter reads that and lays the pages out again:

  • Text with Turkish characters, bold, italic, underline, colours and font sizes
  • Paragraph alignment, indents, line spacing and tab stops
  • Tables with merged cells, borders and cell colours
  • Images, letterhead backgrounds, headers, footers and page numbers
  • Paper size, landscape pages, margins and page breaks
  • Numbered and bulleted lists, and the text of template fields

The text in the PDF is real text: it can be selected, copied and searched.

Limitations

  • The e-signature is not carried into the PDF. A PDF made from a signed UDF is an unsigned copy and not an official one. Keep the original UDF for UYAP and any official use.
  • Times New Roman, Arial and Courier New are replaced by Tinos, Arimo and Cousine, open licensed fonts with the same metrics (licences). Some line and page breaks may differ from the UYAP Document Editor.
  • Notes and comments added to the document are not exported.
  • Elements the tool does not recognise keep their text but may look different.

For an exact copy, open the document in the UYAP Document Editor and use its PDF Olarak Kaydet (Save as PDF) command.

Frequently asked questions

How do I convert a UDF file to PDF?

+
Drop the UDF file on this page. The pages appear below within seconds and the download button saves the PDF. Nothing needs to be installed.

Can I convert an e-signed UDF file?

+
The content is converted, the e-signature is not. The PDF is an unsigned copy and not an official one. Keep the original UDF for UYAP.

Is the text in the PDF selectable?

+
Yes. The text is written into the PDF as text, not as an image, so it can be selected, copied and searched, Turkish characters included.

Is my file uploaded to a server?

+
No. The file is read in your browser and the PDF is built there too. No file is sent to a server.

Does the PDF look exactly like the UYAP Document Editor?

+
Very close, but not always identical. Fonts are replaced by open licensed fonts with the same metrics, so some line and page breaks may shift. For an exact copy use the editor's own PDF export.
