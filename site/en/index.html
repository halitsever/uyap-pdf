What is a UDF file?

UDF (UYAP Document Format) is the document format used by UYAP, Türkiye's National Judiciary Informatics System. Lawyers, citizens and court staff file petitions, statements and reports through UYAP in this format.

Because UDF files open in the UYAP Document Editor, you cannot file a plain PDF directly. This tool turns your PDF into a UDF document that UYAP accepts: every page is embedded as a high-resolution image, and the document's appearance does not change.

To convert a Word or Excel document, save it as PDF first (File → Save As → PDF), then convert that PDF here.

Privacy and security

Legal documents are sensitive, so the conversion runs inside your browser. Your PDF is read, its pages are processed on your device, and the UDF is created on your device too.

No file is sent to a server. Once the page has loaded it works without an internet connection. You can inspect the full code on GitHub.

Frequently asked questions

Will the generated UDF open in UYAP?

+
Yes. The output is compatible with the UYAP Document Editor and UYAP portals. You can open it in the editor to verify after downloading.

Can I edit the text inside the UDF?

+
No. Pages are embedded as images, so the output is like a scanned document. The layout is preserved but the text is not editable. It suits documents that are ready to file.

Is there a file size limit?

+
No fixed limit. Conversion runs in browser memory, so PDFs with hundreds of pages may strain your browser; split such files before converting.

Can password-protected PDFs be converted?

+
No. Remove the password protection first, then convert the file on this page.

Is the tool free? Do I need an account?

+
It is free and open source. There is no signup, installation, or usage limit.

Does it work on phones?

+
Yes, it works in current mobile browsers. Phone memory may fall short on PDFs with many pages; use a computer in that case.
