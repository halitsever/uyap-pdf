What is a UDF file?

UDF (UYAP Document Format) is the official document format of UYAP, Türkiye's National Judiciary Informatics System. Lawyers, citizens and court staff file petitions, statements and reports through UYAP in this format.

Since UDF files only open in the UYAP Document Editor, you cannot file a plain PDF directly. This tool turns your PDF into a valid UDF document: every page is embedded as a high-resolution image, so the document looks exactly like the original.

Your file never leaves your device

Legal documents are sensitive, so the entire conversion runs inside your browser: the PDF is read, rendered and repackaged as UDF on your own device. Nothing is uploaded anywhere, and the page keeps working offline once loaded.

The tool is open source — you can inspect the full code on GitHub.

Frequently asked questions

Will the generated UDF open in UYAP?

Yes. The output is a valid UDF document compatible with the UYAP Document Editor and UYAP portals. You can open it in the editor to verify before filing.

Can I edit the text inside the UDF?

No. Pages are embedded as images, like a scanned document. The layout is preserved pixel-perfectly, but the text is not editable. It is ideal for documents that are ready to file.

Can I convert Word (DOCX) documents?

Export to PDF first (File → Save As → PDF in Word), then convert the PDF here. Fonts, tables, headers and footers are all preserved exactly.

Is there a file size limit?

No fixed limit, but conversion uses browser memory, so very large PDFs with hundreds of pages may struggle. Split such files before converting.
